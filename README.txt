SHOP EASY - BEGINNER E-COMMERCE PROJECT

Files:
- index.html          Home page
- register.html       User registration
- login.html          User login
- products.html       Product dashboard
- product.html        Product details
- cart.html           Shopping cart
- orders.html         My orders
- admin-login.html    Admin login
- admin.html          Admin dashboard
- style.css           Website styling
- script.js           JavaScript functionality

HOW TO RUN:
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select "Open with Live Server".

USER TEST:
1. Register a new account.
2. Login.
3. Open Products.
4. Select a product.
5. Add it to cart.
6. Open Cart.
7. Place order using Cash on Delivery.
8. Open My Orders.

NOTE:
This beginner version uses browser localStorage instead of a database/backend.
Product images are loaded from online image URLs, so internet access is needed for those images.
